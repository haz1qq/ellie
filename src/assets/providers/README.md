# Provider marks

These SVGs are bundled locally and rendered as monochrome identification marks. They are decorative provider identifiers, not Ellie branding or an endorsement claim.

- `openai.svg`: OpenAI blossom mark sourced from Simple Icons 13.21.0, which referenced OpenAI's brand assets. OpenAI trademarks remain subject to OpenAI's brand guidelines.
- `deepseek.svg`: DeepSeek mark sourced from the Simple Icons project (CC0-1.0 collection).

Do not recolor the underlying SVG files. Ellie applies its interface color through a CSS mask so the marks remain legible in dark and forced-color-adjacent themes.
